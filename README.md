# CCDV-F 試験対策問題集

Claude Certified Developer – Foundations（CCDV-F）の試験対策用の問題集です。GitHub Pagesで公開しています。

- 本番と同じ53問のセットを2つ収録（試験ガイドのブループリントにある8分野・25スキルの配点比率に沿って配分）
- 4択の問題に解答すると、すぐに正解・不正解と解説が表示されます
- ☆ブックマークで、後から見返したい問題に印を付けられます（ブックマークした問題だけを解くこともできます）
- 間違えた問題の解き直しと、分野別の正答率を表示します
- 解答の記録はブラウザのlocalStorageに保存されます

## ファイル構成

- `index.html` / `style.css` / `app.js` — アプリ本体（ビルド不要の静的サイト）
- `questions.js` — 問題データ

## ローカルで確認する

`index.html` をブラウザで直接開くだけで動作します。

非公式の学習用問題集であり、Anthropicとは関係ありません。
